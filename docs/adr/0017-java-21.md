# ADR-0017: Target Java 21 LTS

- **Status:** Accepted
- **Date:** 2026-10-28
- **Amends:** ADR-0003 (language and framework unchanged; version only)

## Context
TECH_STACK.md named Java 25 as the current LTS. The development desktop has JDK 21 installed, and
installing JDK 25 is a system change the owner chose not to make now.

## Decision
- Target Java 21 (`<java.version>21</java.version>`), build with `maven:*-eclipse-temurin-21`,
  run on `eclipse-temurin:21-jre`.
- Renovate is restricted to Java 21 images; moving to a newer LTS is a deliberate change with its
  own ADR.

## Alternatives considered
- **Java 25** — newest LTS, but needs a JDK install on the desktop.

## Consequences
- No language features beyond Java 21 (records, sealed types, pattern matching for switch and
  virtual threads are all available).
- Spring Boot 4.1 fully supports Java 21.
- Local builds, CI and images all use the same major version.
